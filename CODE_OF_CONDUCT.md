# Código de conducta

Auditgate adopta el **[Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
como código de conducta para todos los espacios del proyecto: issues, PRs, discusiones y eventos.

En resumen: trato respetuoso, cero acoso, críticas al código y no a las personas.

**Reportes:** escribe a los mantenedores por mensaje privado en GitHub
([@Jawy77](https://github.com/Jawy77)). Los reportes se tratan con confidencialidad.
